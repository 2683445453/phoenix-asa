# 恐爪悬停朝向跟随（revision 12）

## 操作

在“生物与移动 → 恐爪龙大跳”中开启独立开关 **悬停时恐爪朝向跟随玩家**。默认关闭，随配置保存；原有“朝视角方向跳跃”和“360 度射击”开关保持独立。

进入空中悬停后，左右转动视角，恐爪身体水平朝向随玩家视角更新。身体俯仰、侧倾和移动速度保留；上下瞄准不让整只恐爪翻转。转向逐帧执行，不依赖悬停请求间隔，所以把悬停间隔设得较长时也不会故意降低转向频率。

地面、跳跃保护期间、移动、按住空格、F7 调参面板、F2 菜单和游戏后台暂停转向。原有菜单/后台悬停继续运行。下骑、死亡、关闭大跳、关闭本开关或停止全部自动化后不再接管朝向；不会把恐爪强制转回开启前的方向。

## 实现与范围

现有骑乘 360 度功能解除相机和骑手瞄准范围限制，并不保证坐骑身体同步转向。完全静止时，原生 `PhysicsRotation` 也可能不被调用。

本版在已成功提交结束链悬停后，直接调用经过参数校验的 `Actor.K2_SetActorRotation` 修改当前所骑恐爪的根朝向，同时通过 `PrimalDinoCharacter.SetLastMovementDesiredRotation` 更新期望运动朝向。保留速度，不修改相机、不添加移动输入、不修改持续性的旋转标志。正常移动网络同步仍由游戏处理，未新增服务器旋转 RPC。

菜单的“悬停朝向已跟随”仅表示本地读取到的恐爪水平角已对齐。它不能证明服务器认可了射击，也不能保证解决全部无伤害情况。本轮没有运行中的客户端，未完成服务器朝向或伤害实测。

## 测试步骤

1. 退出游戏并更新本版，骑上恐爪，开启大跳及新的朝向跟随开关。按原有操作进入悬停。
2. 左右转动视角约 90°、180°，观察身体是否转向，是否仍能保持悬停。抬头、低头时身体应保持原俯仰。
3. 配合骑乘武器和 360 度射击，对前方、侧方、原先身后方向的同类目标射击；以目标实际掉血为准，区分弹道、命中特效和真实伤害。
4. 关闭新开关进行对照；再次开启后应恢复跟随。检查跳跃方向和力度未受影响。
5. 若身体已转但后方射击仍无伤害，请反馈所用武器、目标类型、菜单朝向状态，以及是否出现身体转回。后续需在本地测试服对照服务器朝向和伤害。

## 验证与诊断

- `DeinoHoverFacing.inl`：只处理当前坐骑对应的运动组件；所有接口及参数先校验，拒绝非法数值，读回水平角判断本地是否生效。
- `DeinoFlightRules.h::Control::Hovering`：仅在实际提交悬停后启用；间隔等待期间保留，移动、跳跃、保护或落地清除。
- `tests/deino_hover_facing.cpp`：执行生产转向函数，测试角度跨越 ±180°、保留俯仰/速度、对象不匹配、接口失败、无效值和被修正的朝向。
- `tests/feature_expansion.cpp`：悬停状态门控、保存/加载、旧配置默认关闭以及停止全部。
- 记录新增 `hover_follow_view` 与每 250 ms 的 `# hover_facing` 行，含状态、原角度、目标角度和本地读回角度；不冒充服务器观测。
- 已安装客户端原生入口只读审查：`release/diagnostics/deino-hover-facing-native-20260930.txt`。运行时仍逐次校验参数布局；本地请求与专服效果需分开验证。
