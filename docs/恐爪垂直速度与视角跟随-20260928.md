# 恐爪垂直速度与视角跟随（revision 9）

> 本文保留 revision 9 历史行为。当前 revision 10 已用完整视角方向与独立总力度替代阈值模式，操作及配置迁移见 [恐爪朝视角跳跃](恐爪视角定向跳跃-20260928.md)。

## 修改内容

- 手动垂直速度从 0～300 扩展到 **−300～300 m/s**；负值向下，正值向上。配置、骑乘面板滚轮、快捷滚轮和三个手动预设均支持负数。地面大跳仍使用原倍率。
- 新增独立开关“垂直速度跟随视角”，默认关闭。关闭时保留并使用原手动速度；开启时按当前视角计算下一次空中跳跃的垂直分量。
- 可设置低头角度阈值（−90°～−1°）、抬头角度阈值（1°～90°）以及垂直速度上下限（各 −300～300 m/s）。低头阈值对应下限，抬头阈值对应上限，区间内线性变化，超出后限幅。菜单会联动另一端以保证速度下限不大于上限；配置文件中的颠倒值在加载时交换。
- 默认 −45° 对应 −30 m/s，+45° 对应 +30 m/s，因此平视为 0，±22.5° 对应 ±15 m/s。非对称角度或速度设置下，平视不一定等于 0。
- 水平倍率仍独立，仅左右视角影响水平朝向。按空格时读取视角并确定本次速度；之后转动视角只更新下一跳预览，不修改正在进行的跳跃。
- HUD 显示有效垂直速度与俯仰角；原生光束、黄色回退预览和终点标记使用同一速度计算。自动模式下，滚轮和预设仍编辑保存的手动值；关闭自动模式后使用该值。四项视角参数和开关保存到配置，不随三个手动预设切换。

计算规则为 `t = clamp((俯仰角 - 低头阈值) / (抬头阈值 - 低头阈值), 0, 1)`，`垂直速度 = 下限 + t × (上限 - 下限)`。UE 的环绕角度先转换成有正负的俯仰角。无效数字或不合法区间不会提交跳跃。

## 测试步骤

1. 完全退出客户端，使用原加载器更新，再骑恐爪。原有菜单/后台悬停和光束自动加载保持原实现。
2. 关闭“垂直速度跟随视角”，将“手动垂直速度”设为 −5 m/s。空中查看光束，再按一次空格，确认向前且向下；切回 +5 m/s 对比。给向下运动留出足够高度。
3. 开启“垂直速度跟随视角”，先用较低速度：低头 −45°、抬头 +45°、速度下限 −10、上限 +10 m/s。平视应显示约 0，低头/抬头逐渐变化，超过阈值后停在 ±10。
4. 分别在平视、低头和抬头状态下各按一次空格。确认实际方向与 HUD/光束一致；转动视角本身不应自动起跳。
5. 关闭开关，应恢复第 2 步保存的手动速度。保存配置并重新加载，检查负速度、四项阈值和开关都保留。

当前离线测试覆盖负值边界、线性插值、两端限幅、315°→−45° 环绕角度、无效数字、向下预览、配置保存与旧配置默认行为。新增负速度和视角模式的服务器实际运动仍待游戏实测；只有之前固定组合的预览具有实测基准，其余仍为模型估算。
