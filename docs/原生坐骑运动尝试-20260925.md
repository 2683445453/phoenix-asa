# 恐爪龙 / 穴角兔原生运动入口尝试

用户允许尝试服务器插件、模组以外的路径。本次仅新增客户端功能，没有部署服务端修改；没有要求用户进行分轮采样。

## 已实现

新增默认关闭的“原生坐骑跳跃”和“原生坐骑松键悬停”，仅当前骑乘恐爪龙或穴角兔生效。配置存取、停止清单、菜单及双语文本已接入。

- 轻按F6触发一次，按住不重复；首次开启或切换坐骑时已按住的键不触发，连续按下最短间隔250毫秒。有菜单/快捷功能F6绑定冲突时暂停该功能。
- 地面：保留当前水平速度，把垂直目标速度设为滑条值，默认20m/s，可调1–100m/s。
- 空中：保留当前垂直速度，沿控制视角的水平朝向追加速度，默认每次10m/s，可调1–100m/s。附加加速的水平上限默认60m/s，可调1–200m/s；不强行降低原本已经超过该值的速度。
- 默认通过原生ACharacter::LaunchCharacter提交目标速度。开启“使用冲量入口AddImpulse”后，通过原生UCharacterMovementComponent::AddImpulse提交相同目标与当前速度的差值，bVelocityChange=true；不覆盖引擎的最大垂直冲量规则。
- 悬停：原本处于Falling、无移动输入且空格/F6释放时，原生SetMovementMode切到Flying并StopMovementImmediately。移动输入或空格/F6退出悬停并恢复此前模式。它是本地运动尝试，服务器仍可能纠正。

F6是额外触发键，正常空格继续走游戏原生行为。已有蓝图大跳及兔子蓄力参数可单独使用；这两个原生入口不依赖那些速度字段。

## 校验与恢复

所有调用均在既有游戏线程Tick执行，沿用人物存活、前台窗口、菜单/聊天输入与当前骑乘检查；自由相机开启时暂停。只允许当前本地Authority/AutonomousProxy对象，水中、未知自定义运动模式不执行。恐爪龙UberpounceState不是0时暂停，不改抓附/扑击状态。

原生函数需通过Native且非Net标志、参数总大小、字段类型/偏移/元素大小及布尔存储检查。已重新读取当前客户端反射，确认LaunchCharacter=32字节、AddImpulse=40、SetMovementMode=2、GetLastInputVector/GetPendingInputVector=24、StopMovementImmediately=0。证据：release/diagnostics/native-mount-20260925/native-signatures.json。旧对象快照曾因GC失效，读取失败后已重新完整抓取；不沿用旧对象地址写入。

悬停保存弱对象身份和之前的MovementMode/CustomMovementMode；只在本功能仍持有Flying/0时恢复。关闭、下龙、菜单/失焦、切换对象和卸载均进入恢复路径；若引擎/服务器已改成其他模式，不用旧值覆盖。已发生的位移和速度脉冲不会倒放或恢复到旧轨迹。

## 范围限制

以下是首版记录。后续已新增可选运动 Hook 入口，操作、验证与最新产物见 [Hook版说明](坐骑运动Hook与服务器抓附路径-20260925.md)。

本版实现的是两个原生函数入口和运动组件悬停，不是任意原生函数Hook，更没有拦截服务器纠正或改写ServerMove。调用成功不代表服务器接受，不宣称官服空中连跳或悬停已实现。

抓附/扑击的状态路径继续作为审查方向；此前确认普通ServerRequestJump有Walking、速度大小和间隔门槛，不能将其当作自由空中跳跃入口。若进一步做原生Hook，需要针对当前版本验证具体函数边界与调用约定，而非猜测地址。

代码：src/internal/Hack/NativeMount.inl、NativeMountRules.h；调度/重置在FeatureExpansion.inl。向量和触发边沿、配置往返/停止行为由tests/feature_expansion.cpp覆盖。

验证完成：功能回归和生产补丁测试通过；Release编译、启动器自检通过；语言与归档一致性通过（905键、702文本）。DLL直接部署到dist/phoenix/phoenix.dll，SHA256=4fe6b8cd051eb3a2d164dbd6013676924b436b361287e22c13fa7d412308e339。尚未进行游戏内效果验证。
