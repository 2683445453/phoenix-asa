# 独立透视与真实骨骼（2026-09-30）

入口：**透视显示 → 独立透视 → 启用独立透视**。总开关默认关闭，旧配置不会自动启用。开启后默认显示人物骨骼和建筑三维线框；生物可单独勾选。

人物／生物骨骼读取当前模型的真实骨骼名称、父子关系和当前姿态的世界坐标，不使用固定人形骨架。每帧重新读取位置，只有骨骼拓扑被缓存。模型变化、对象重建和换世界时刷新缓存。不存在有效模型、投影失败或坐标异常时跳过对应线段。

骨骼仍需转换到屏幕才能显示。新绘制共用项目现有 `ProjectToCanvas`：先取得实际视口投影，再换算为 Canvas 的 ClipX／ClipY 坐标；字号、线宽也换算为相同坐标。屏幕叠加不必然产生偏移，但运行中视口、DPI 或游戏接口变化仍需实机确认。本功能没有给游戏渲染器增加骨骼穿墙材质，而是以模型实际骨骼位置绘制可穿过场景遮挡的屏幕线段。

建筑使用其自身可见模型组件的世界包围盒，不包含炮塔范围球、碰撞触发器或附着的其他建筑。线框为十二条包围盒边，旋转建筑使用世界轴对齐包围盒；它不是墙面描边，也不是建筑网格的全部边。

可独立设置：

- 人物、生物、建筑，及隐藏友军。
- 骨骼、人物／生物方框、建筑线框、名称、距离。
- 人物／生物距离和建筑距离，分别为 1–2000 米。
- 线宽 0.5–5 像素、字号 10–32 像素。
- 非友军、友军、非友军建筑三组 RGBA 配色。

这些设置单独持久化，不依赖旧人物／生物开关、建筑名称／类型筛选、简洁战斗模式或原生模型轮廓。原有透视仍可同时开启，因此两套名称、方框可能同时出现。

仅绘制客户端已加载的存活对象；隐藏对象、建筑预览、死亡对象和本地人物不绘制。按距离优先取最多 128 个对象，每帧至多 32 套骨骼、4096 次骨骼位置查询、4096 条线段；初次发现的骨骼拓扑每帧最多建立两套。密集场景可能省略远处骨骼，超过 1024 根骨骼的模型跳过骨骼绘制。屏幕边缘线段进行裁剪，标签没有完整空间时隐藏。若游戏停止更新遮挡模型的动画，骨骼姿态也可能暂停；本功能不修改动画刷新策略。

验证：`tests/run-independent-overlay-tests.ps1` 已通过，覆盖线段裁剪、异常输入、包围盒边、100%–200% 坐标换算、独立配置往返、旧配置默认关闭及参数限幅。`tests/run-interface-render-tests.ps1 -OverlayOnly` 已通过，覆盖独立页面中英文、关闭隐藏参数、窄窗口与 ImGui 栈。完整界面回归在笔记实验的“所有经验笔记”下拉框可用性断言失败，未宣称完整套件通过。最终 Release 已编译并生成 `dist/phoenix` 及 `dist/phoenix.zip`；实际游戏内骨骼、建筑贴合及帧率尚未验证。

实机检查：加载新版 DLL，关闭旧模型／信息绘制，仅启用独立透视。先观察近处人物，再启用生物并检查尾部、翅膀和关节随姿态移动；改变窗口大小及分辨率，检查骨骼与模型对齐；检查旋转建筑和炮塔线框；关闭总开关确认新绘制立即消失。保存并重新读取配置，确认原生模型显示没有被一并启用。
