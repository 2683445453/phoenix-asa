# phoenix 本地授权验证记录

日期：2026-09-15。

补充：排查“无法连接授权服务”确认原因为本机服务未启动。新增后台 `start/status/stop` 管理命令，并验证 Windows PowerShell 5.1 下的启动、重复启动不生成副本、停止、状态查询及数据目录权限设置。使用无效诊断码验证了实际 phoenix 启动器到本地服务的连接，未修改用户激活码或授权记录。

## 已完成

- 本地授权验证版与普通开发版均通过 Release x64 编译，输出目录和中间目录独立。
- 12 个授权测试方法通过，其中签名测试包含 18 组正常／异常凭证与时间边界。
- 已测试：激活码、首次起算不重置、设备绑定、并发激活、换机解绑、到期、续期、吊销／恢复、服务端普通时间回拨、状态持久化、HTTP 请求限制、Windows 原生验签、重复 JSON 字段、签名／字段篡改、DPAPI 缓存篡改、拒绝非本地明文 HTTP、断网时旧凭证到期、运行中续期及吊销。
- 实际编译的 DLL 在独立测试进程中直接加载：缺少激活或授权已吊销时，在读取游戏世界之前拒绝初始化并卸载。
- 实际分发启动器通过帮助、文件检查、旧更新入口拒绝、激活、查询授权和持续到期验证；激活码没有出现在程序输出和持久化日志中。
- 本地 ZIP 中的 EXE／DLL 摘要与验证文件一致；不含私钥、授权数据库、缓存会话、PDB 或待更新文件。
- 既有 gameplay-extensions 回归检查通过，涵盖配置往返和相关既有规则；SDK 编译仍有原有枚举告警。

自动化测试使用临时服务和测试目录，测试完成后关闭，不会把测试卡密写入本地正式测试数据目录。`.local-license` 中已初始化可供后续手动验证的测试签名密钥和空数据库。

## 尚未验证或实施

- 未启动或操作游戏；授权成功后的游戏内运行、到期后的具体状态恢复、加载画面和卸载表现仍需实机验证。
- 本地开发 HTTP 服务尚未替换为生产服务器，未部署正式 HTTPS 域名、正式密钥、加壳或 Authenticode 签名。
- 本机所有者仍能控制本地服务、数据库及系统快照；当前版本用于验证授权流程，不提供服务器部署后的管理边界。

操作入口及后续迁移步骤见[本地授权验证说明](phoenix-本地授权验证.md)。
