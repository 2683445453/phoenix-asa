# phoenix 界面重排 · macOS Vibrancy

先按任务分类，再进入功能，最后调整参数。默认打开常用功能；所有功能都能从分类列表直接找到。

| 分类 | 功能入口 |
| --- | --- |
| 常用功能 | 自动锁定、泰克长矛、骑乘采集、自动吸包、自动制作、自由视角；运行中功能和停止自动化 |
| 战斗辅助 | 自动锁定、枪械与射击、锁定指示、泰克长矛 |
| 透视显示 | 对象与模型、信息排版、建筑筛选、物品水源与威胁 |
| 资源采集 | 骑乘采集、资源筛选与高亮、扫描诊断 |
| 自动化 | 拾取与吸包、生存补给、钓鱼、水晶、制作、维修、喂养与治疗、生物与移动、笔记与上传 |
| 工具 | 背包、生物列表、建筑列表、Lua 脚本 |
| 设置 | 界面、快捷键、系统操作、配置、语言 |

桌面为三级面板：分类栏、功能列表、详情。窄窗口将分类栏改为下拉选择，进一步缩窄时功能列表也改为选择框。详情独立滚动，不把所有参数放进首页。

开关始终可见，子参数只在功能启用后显示，关闭不清空参数。资源类型是高亮与采集的共享筛选，不随其中一个功能关闭而丢失。说明与注意事项由全局“显示说明”控制并保存；运行状态、错误和快捷键冲突始终可见。诊断有独立入口。

只使用 #1c1c1e、#2c2c2e、#3a3a3c 背景，1px 白色半透明边框，圆角不超过 12px。蓝色 #0a84ff 仅用于交互文字。标题采用 Georgia 并合并中文衬线字形，正文使用系统无衬线字体。无渐变、发光、位移或缩放动画。

调色工具采用纯色预设、十六进制输入、RGBA 数值、复制粘贴和打开时颜色还原；不使用渐变色轮。快捷键支持组合键、冲突拒绝、取消和清除，游戏失焦或输入文字时不切换功能。紧急停止只关闭功能，不自动恢复。

参数上限仅扩展可验证的范围，并在界面、配置与运行时使用一致限制。搜索范围不等于服务器允许的交互距离。启动展示只呈现 phoenix 字标、凤羽线条、就绪状态和实际菜单键，可跳过，禁止虚构加载进度。
