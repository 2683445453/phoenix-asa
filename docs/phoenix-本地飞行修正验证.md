# 本地自由飞行修正 · 2026-09-16

按用户澄清，“灵魂出窍”现为本地自由相机，操作类似管理员飞行；人物位置不随相机移动。此前向服务器请求 Fly / Walk 的实现已替换。

使用：步行时开启“灵魂出窍（本地飞行，双击空格）”，双击空格进入／退出，WASD 移动、空格上升、Ctrl 下降、Shift 临时加速、鼠标转向，Esc 返回。开启开关期间空格用于相机控制；关闭开关恢复普通跳跃。人物仍受游戏物理和伤害影响。

实现只修改本地相机的当前帧、上一帧及 ViewTarget 视角，原生相机更新前恢复原值，更新后应用本地视角。未调用管理员命令、角色移动、切换控制器或远程建造接口。移动和转向输入仅归还本功能持有的忽略计数；接口临时失效时保留待恢复状态并重试。

菜单、聊天、背包、失焦、死亡、骑乘、切换角色、世界或视角目标时退出。原生输入接口不存在、签名不符或视角含无效数值时不进入。进入前释放自动战斗输入。
