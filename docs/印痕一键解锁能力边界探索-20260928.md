# 印痕一键解锁能力边界探索（2026-09-28）

## 结论

研究对象是**连接独立服务器、没有服务器管理员权限的普通本地客户端**。

| 目标 | 本轮结论 | 证据强度 |
| --- | --- | --- |
| 一键学习当前符合服务器条件的普通印痕 | 存在原生学习 RPC，可设计为逐项批量学习；按服务器实际费用扣点，费用可以为零，仍受服务器规则约束 | 接口、运行时反射与原生检查已核验；未实现、未进行联机行为测试 |
| 无条件解锁全部印痕，包含真正的泰克印痕 | 已核验的原生路径不支持；没有发现普通客户端可用的全解锁入口 | 普通学习入口、权威解锁、泰克资格检查均有代码证据 |
| 在本地调用 `ServerUnlockEngram` 并设置 `bForceUnlock=true` | 不成立：它不是网络 RPC，且实现检查服务器权威角色 | 当前客户端运行时反射及原生代码直接确认 |
| 管理员授予、Boss 奖励或服务器自动解锁配置 | 属于服务器授权/规则范围，不能算普通客户端自身能力 | 管理员命令与普通学习分开核查；本轮没有执行授予或修改配置 |
| 本地显示“已解锁”、弹出通知、背包出现配方 | 不能证明服务器学习成功或保存成功 | 复制方向、权威数据字段与结果写入位置已核验 |

这里的“全部”不能通过把“批量发送学习请求”改个名字来成立。普通印痕也可能因等级、点数、前置、隐藏设置或内容资格而无法学完。服务器模组或特殊配置可能改变结果，本轮不外推到所有服务器。

## 普通学习的实际链路

当前客户端：

1. `ServerRequestApplyEngramPoints` 的反射入口 RVA `0x601d6f0`，转到玩家状态虚表字节槽 `0xfe0`；CDO 对应原生实现 RVA `0x674ffb0`。
2. 实现遍历 GameData 的 `EngramBlueprintEntries`，用 `BluePrintEntry` 匹配请求中的物品类，读取**执行该实现一侧自己的印痕定义**。
3. RVA `0x6750151` 检查条目 `+0x58` 的 `0x02` 位。运行时反射确认为 `bCanBeManuallyUnlocked`，必须为真。
4. RVA `0x675017d`–`0x675018b` 固定以通知开启、强制参数关闭的方式调用 `ServerUnlockEngram`（当前实现 RVA `0x67501b0`）。普通 RPC 没有可传入的强制解锁参数。
5. `ServerUnlockEngram` 在 `0x67501be` 比较 Actor 的 `Role`（`+0x348`），小于 `3` 直接退出。同样的权威门槛也内联在反射 exec 的 `0x602027a`。
6. 普通远程玩家的资格路径进入 `MeetsEngramRequirements`，当前客户端 RVA `0x6a00130`。随后还检查服务器隐藏规则，才扣除服务器印痕点数并写入服务器印痕集合。

服务器静态样本的对应入口：`ServerRequestApplyEngramPoints_Implementation=0x4f3b300`；`ServerUnlockEngram=0x4f406a0`；`MeetsEngramRequirements=0x51572a0`。符号与关键检查和当前客户端互相对应，不按地址固定差值推算。

资格函数已核验：

- `EngramGroup == 8`，或 `bForceIsTekEngram == true`，直接拒绝。
- 检查角色等级、可用印痕点数、是否已学、前置集合及内容资格。
- 外层另有服务器隐藏印痕检查；不能仅用客户端模板的默认点数/等级构造最终资格表。
- `ServerUnlockEngram` 内还有依赖 Owner 本地控制状态的分支，会改变资格检查路径。服务器样本的虚表已精确核验为 `IsLocallyControlledByPlayer → Owner → IsLocalController`，最后一个函数在该专服编译中固定返回 false，因此专服走完整资格检查。当前客户端也确认同结构的 Owner 分支。本结论不能外推到单机或监听主机；客户端非权威调用先被 Role 检查挡住，普通学习 RPC 仍有服务器手动学习门槛。

因此，在本地改 `RequiredEngramPoints`、`RequiredCharacterLevel` 或手动学习标志不会改掉服务器执行时读取的定义；改客户端印痕数组也不是服务器新增学习记录。

本轮快照包含 `880` 个已加载印痕 CDO；这是**当前进程已加载模板**的数量，不代表完整游戏目录或当前服务器可学数量。

## 其他候选路径

### 管理员命令

服务器样本 `ABasePlayerController.ServerCheat_Implementation` 在进入命令执行前检查 `HasValidAdminIP()` 以及服务器 Controller 的 `bIsAdmin`（`+0xab8` mask `1`）。`RemoteServerCheat` 也先检查管理员位再进入相应路径。

`GiveEngrams` / `GiveEngramsTekOnly` 的实现能写入服务器玩家印痕集合，但这属于管理员授予路径，且仍有其自身筛选与服务器规则。仅在本地调用 CheatManager、改本地管理员位，不能证明服务器授权通过。本轮没有执行任何管理员命令。

### ServerGiveItem 的 bGiveEngram

该 RPC 的参数看上去是另一个入口，因此单独核查了实际虚表实现。

- 当前客户端 exec RVA `0x5ff3290` 使用 Controller 虚表字节槽 `0x1aa8`。
- 当前 CDO 对应实现 RVA `0x1a35790`，只释放传入路径字符串后返回，没有发物品或授予印痕逻辑。
- 精确匹配符号的服务器样本 `ServerGiveItem_Implementation` 同样为空操作，只清理传值字符串。

结论只针对本轮核查的原生实现；不能因为 SDK 留着 `bGiveEngram` 参数就将其列为可用授予能力，也不据此断言其他模组覆写永远相同。

## 后续如果开发“批量学习”

合理功能名称是“一键学习可学印痕”，当前状态为**可进入实现设计，尚未实测**：

1. 从当前 GameData 有效目录收集条目，处理追加、移除和重映射；RPC 参数传 `UPrimalItem` 类，不传 `UPrimalEngramEntry` 类。
2. 按当前可见等级、点数、前置、手动学习标志、已学状态作候选筛选；泰克组及强制泰克单独标注为奖励解锁。
3. 单次任务在游戏线程逐项限速发送，等待服务器复制确认后继续；点数不足/无进展时停止，提供取消，不高频重试被拒绝项。
4. 状态分别显示“候选 / 已请求 / 服务器确认 / 未满足条件”。客户端提示弹窗不计成功。
5. 如实施，按开发文档 §17 接入默认关闭、菜单、语言、停止与卸载清理，再做适当离线规则验证和构建。

双端验收必须使用独立测试角色，记录学习前后**服务器** `EngramItemBlueprints` 增量、`FreeEngramPoints` 变化、复制结果；点数变化应与服务器实际费用一致，零费用条目不要求点数减少。重连后再确认持久化。对照组覆盖合法普通条目、点数不足、等级不足、前置不足、真正泰克及名字含 Tek 的普通条目。不能用预先执行管理员全解锁的角色证明普通客户端能力。

## 证据产物与复现

根目录：`release/diagnostics/engram-research-20260928/`。

- `evidence-summary.json`：13 个接口的当前 flags、参数、模板样本和基线摘要。
- `client-reflection/`：客户端类反射、已加载对象和模板值；原始对象快照仅用于本地诊断。
- `client-native-entry.txt`：当前反射 exec 与解锁权威检查。

- `client-unlock-and-eligibility.txt`：当前解锁和资格判断的指令范围。
- `client-owner-and-give-item.txt`：Owner 分支与 ServerGiveItem 实际虚表目标。
- `server-native/`：按服务器 SHA256 匹配符号的离线反汇编、函数列表、`provenance.json` 及 `vtable-proof.json`。

原生指令的范围导出可能包含函数末尾填充或下一个函数前缀，判断以注明的入口、分支目标和返回路径为准；离线导出的符号边界也不等于源码函数的精确边界。

反射采集复用 `release/diagnostics/inspect_feature_runtime.py`，增加 `PHOENIX_CAPTURE_TOKENS=primalengramentry,engram,shooterplayerstate,shootercheatmanager,primalgamedata,shootergamemode,shootergamestate`；原生读取复用 `read_native_routes.py`。摘要由 `summarize_engram_research.py` 从保存的快照生成，服务端离线导出脚本为 `disassemble_server_engrams_20260928.py`。重新采集必须先确认新 PID、SDK 基础地址、函数布局与原生目标，本文地址不能直接用于未来版本。

**最终分级：普通印痕批量条件学习有原生入口；普通客户端无条件全解锁含泰克，在已核查路径上不成立。服务器行为与持久化实测未进行。**
